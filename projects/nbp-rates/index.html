Raport kursów walut, który robi się samAn FX report that builds itself

W wielu firmach ktoś codziennie wchodzi na stronę NBP, kopiuje kursy do Excela i wysyła je dalej. Zautomatyzowałem ten proces od początku do końca: dane pobierają się same, historia rośnie, dashboard poniżej się aktualizuje, a przy dużym ruchu kursu pojawia się alert.In many companies someone visits the NBP website every day, copies rates into Excel and forwards them. I automated the whole process end to end: data is fetched automatically, history builds up, the dashboard below refreshes, and a big move in a rate raises an alert.

Workflow startuje automatycznie w najbliższy dzień roboczy o 11:40 UTC. Można go też uruchomić ręcznie: GitHub → Actions → nbp-rates → Run workflow. Przy pierwszym przebiegu skrypt pobiera rok historii.The workflow starts automatically on the next working day at 11:40 UTC. It can also be run manually: GitHub → Actions → nbp-rates → Run workflow. The first run back-fills a year of history.

Jak to działaHow it works

  1. HarmonogramScheduleGitHub Actions uruchamia workflow w każdy dzień roboczy.GitHub Actions starts the workflow every working day.
  2. TestyTestspytest sprawdza logikę na danych testowych, zanim cokolwiek się zapisze.pytest checks the logic on test data before anything is saved.
  3. PobranieFetchTylko brakujące dni z API NBP, w paczkach po 90 dni.Only the missing days from the NBP API, in 90-day chunks.
  4. KPIZmiana d/d, 7 i 30 dni, zakres 90 dni, zmienność.Day/day, 7- and 30-day change, 90-day range, volatility.
  5. PublikacjaPublishCommit danych i raportu Markdown – strona odświeża się sama.Data and a Markdown report are committed – the site refreshes itself.
  6. AlertAlertRuch powyżej 1% w sesji zakłada zgłoszenie (Issue) z podsumowaniem.A move above 1% in one session opens an Issue with a summary.

Dlaczego tak, a nie inaczejDesign choices

  • Bez serwera i bez kosztów. Harmonogram, obliczenia i hosting robi GitHub. Nie ma nic do utrzymywania.No server, no cost. GitHub handles the schedule, compute and hosting. There's nothing to maintain.
  • Idempotentność. Ponowne uruchomienie tego samego dnia niczego nie psuje ani nie dubluje – skrypt dociąga tylko brakujące notowania.Idempotent. Running it twice on the same day doesn't break or duplicate anything – the script only fetches missing quotes.
  • Historia w repozytorium. Każdy dzień to commit, więc widać dokładnie, kiedy i jakie dane się zmieniły.History in the repo. Every day is a commit, so it's clear exactly when and what data changed.
  • Alert tam, gdzie zespół już pracuje. Zgłoszenie na GitHubie wysyła powiadomienie e-mail bez konfigurowania skrzynki czy haseł. W firmie ten sam krok może wysyłać wiadomość na Teams lub Slacka.Alerts where the team already works. A GitHub Issue sends an email notification with no mailbox or password setup. In a company the same step could post to Teams or Slack.
